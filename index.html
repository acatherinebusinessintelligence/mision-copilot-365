Tu misión con Microsoft Copilot

Avanzarás por tres niveles: de asistente personal a copiloto de proyectos. Cada etapa refuerza criterio humano, trazabilidad y uso responsable.

Nivel 1 · Asistente personal

Comprender correos, resumir y organizar información sin inventar datos.

Nivel 2 · Productividad y colaboración

Adaptar comunicaciones, comparar documentos y priorizar el trabajo del equipo.

Nivel 3 · Gestión de proyectos

Integrar fuentes, analizar riesgos y preparar recomendaciones para dirección.

Sesión 1

Copilot para la productividad individual

Utilizar Microsoft Copilot en Outlook, Teams, Word y Excel para comprender información, organizar el trabajo, preparar comunicaciones y convertir contenido disperso en entregables listos para validar.

Método de trabajo: abre la aplicación Microsoft 365 indicada, ejecuta Copilot con el prompt y entrega el resultado en el formato solicitado (columnas o estructura indicadas). No se exige un archivo con nombre fijo salvo que el reto lo diga. No inventes datos: si falta información, escribe “no especificado”.

La Dirección de Operaciones autoriza modernizar tableros y sistemas de monitoreo en una instalación urbana con demanda creciente. El objetivo es mejorar la confiabilidad del servicio bajo plazo, presupuesto controlado, requisitos de seguridad, consideraciones ambientales y comunicación con la comunidad.
