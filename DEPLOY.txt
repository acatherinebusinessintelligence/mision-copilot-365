A) PRIMER DESPLIEGUE

   SMTP_PORT=587

   APP_BASE_URL=https://dracorazonia.pythonanywhere.com
   EMAIL_WEBHOOK_URL=<URL /exec del Apps Script, ver sección D>
   EMAIL_WEBHOOK_SECRET=<mismo secreto del script>

4) Web app (pestaña Web)
   - Add a new web app > Manual configuration > Python 3.10

   - Working directory: /home/dracorazonia/Clases_Enel

B) ACTUALIZAR (cada vez que hay cambios)
========================================
En tu PC:   git add ... && git commit && git push
En PythonAnywhere (Bash console):
   cd ~/Clases_Enel
   git pull
   source venv/bin/activate && pip install -r requirements.txt   # solo si cambió requirements.txt
Luego: pestaña Web > Reload (y en cuentas free: "Run until 3 months from today").
Verifica /health: el campo "version" debe ser el nuevo.

Si git pull se queja de cambios locales en el servidor:
   git status            # revisa qué cambió (no debería haber nada salvo .env/data, que están ignorados)
   git stash             # o descártalos si eran ediciones hechas a mano en el servidor


C) RESPALDO DE LA BASE DE DATOS (antes de cada actualización)
==============================================================
   cp ~/Clases_Enel/data/mision.db ~/mision_backup_$(date +%Y%m%d).db
   Restaurar: cp ~/mision_backup_AAAAMMDD.db ~/Clases_Enel/data/mision.db  y Web > Reload
