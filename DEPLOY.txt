B) ACTUALIZAR (cada vez que hay cambios)
========================================
En tu PC:   git add ... && git commit && git push
En PythonAnywhere (Bash console):
   cd ~/Clases_Enel
   git pull
   source venv/bin/activate && pip install -r requirements.txt   # solo si cambió requirements.txt
Luego: pestaña Web > Reload (y en cuentas free: "Run until 3 months from today").
Verifica /health: el campo "version" debe ser el nuevo.

Si git pull se queja de cambios locales en el servidor:
   git status            # revisa qué cambió (no debería haber nada salvo .env/data, que están ignorados)
   git stash             # o descártalos si eran ediciones hechas a mano en el servidor

F) CLASE EN VIVO (cuenta de administración)
===========================================
Abre dos pestañas con tu sesión de administración:
1. /presentar  -> el curso en modo instructora. En cada paso, parada de
   herramientas, cierre y compendio, botón
   «Presentación» (barra superior): portada, qué vamos a hacer (agenda con
   tiempos), cómo funciona, cómo trabajaremos, pulso del grupo, «lo lograste
   si…» y cronómetro. Teclas: flechas, F (pantalla completa), Esc (cerrar).
   En la diapositiva «Pulso del grupo» pulsa «Abrir votación en las
   pantallas»: a cada estudiante le aparece la pregunta y los resultados se
   actualizan solos. Ciérrala al terminar (se cierra sola a los 20 minutos).
2. /admin/en-vivo -> quién está conectado, en qué paso va cada uno, mapa de
   las 25 actividades y, al hacer clic en un nombre, lo que ha escrito en la
   plataforma (no sus conversaciones con Copilot).
Al final: /admin/resultados -> gráfica del grupo sin nombres (avance por
módulo, autoevaluaciones, confianza antes/hoy, ideas, votaciones y primeros
pasos). Botón «Proyectar» para pantalla completa.
Las tablas nuevas (presence, pulse_votes, app_settings) se crean solas al
recargar la web app; no hay que migrar nada.
