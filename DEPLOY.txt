B) ACTUALIZAR (cada vez que hay cambios)
========================================
En tu PC:   git add ... && git commit && git push
En PythonAnywhere (Bash console):
   cd ~/mision-copilot-365
   git pull
   source venv/bin/activate && pip install -r requirements.txt   # solo si cambió requirements.txt
Luego: pestaña Web > Reload.
Verifica /health: el campo "version" debe ser el nuevo.

Si git pull se queja de cambios locales en el servidor:
   git status            # revisa qué cambió (no debería haber nada salvo .env/data, que están ignorados)
   git stash             # o descártalos si eran ediciones hechas a mano en el servidor


C) MIGRAR DESDE UNA CARPETA SUBIDA A MANO (p. ej. ~/Clases_Enel sin git)
=======================================================================
   cd ~
   git clone https://github.com/acatherinebusinessintelligence/mision-copilot-365.git
   cp ~/Clases_Enel/.env           ~/mision-copilot-365/.env
   mkdir -p ~/mision-copilot-365/data
   cp ~/Clases_Enel/data/mision.db ~/mision-copilot-365/data/mision.db   # conserva estudiantes y avance
   cd ~/mision-copilot-365 && python3.10 -m venv venv && source venv/bin/activate && pip install -r requirements.txt
   Pestaña Web: cambia Source code / Working directory / Virtualenv a ~/mision-copilot-365 y Reload.
   Cuando todo funcione, puedes borrar ~/Clases_Enel.
