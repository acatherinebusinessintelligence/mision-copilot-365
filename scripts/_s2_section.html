Sesión 2

Copilot y Power Automate para la gestión inteligente de proyectos

Automatiza el ciclo de un proyecto empresarial combinando Copilot, Power Automate, Outlook, Word, Excel, SharePoint, Teams y PowerPoint.

La sesión comienza con la recepción de un correo que contiene la solicitud y la ficha inicial de un proyecto. A partir de esta información, los participantes construirán un flujo que almacenará los documentos, extraerá y estructurará los datos, registrará el proyecto, consolidará el presupuesto, analizará los riesgos, generará un informe, solicitará aprobación humana y preparará una presentación ejecutiva.

Cada reto utilizará los resultados del reto anterior. El objetivo no es practicar aplicaciones por separado, sino comprender cómo se conectan para gestionar un proyecto de principio a fin.

Caso transversal · Proyecto Horizonte. Power Automate es la columna vertebral. Copilot estructura y redacta; la aprobación humana nunca la completa Copilot.

Objetivo de aprendizaje

Al terminar la sesión, el participante podrá:

  • Crear un flujo automatizado a partir de un correo.
  • Guardar y organizar archivos adjuntos.
  • Extraer información estructurada de un documento Word.
  • Utilizar datos dinámicos dentro de Power Automate.
  • Registrar información de proyectos en Excel.
  • Construir un presupuesto.
  • Crear y priorizar una matriz de riesgos.
  • Generar un informe Word desde una plantilla.
  • Incorporar una aprobación humana.
  • Preparar una presentación ejecutiva con Copilot.
  • Mantener trazabilidad entre fuentes, análisis y entregables.

Caso transversal · Proyecto Horizonte

La organización recibe por correo la solicitud de iniciar el Proyecto Horizonte.

El correo incluye una ficha Word con: nombre, código, objetivo, alcance, patrocinador, líder, fechas, presupuesto preliminar, entregables, dependencias, restricciones, riesgos iniciales y criterios de éxito.

Los datos y archivos producidos en cada reto deben utilizarse en el siguiente.

Archivos oficiales de la sesión

Resultado de la sesión: al terminar, habrás construido el flujo completo de un proyecto: desde la recepción de la solicitud por correo hasta la generación del presupuesto, la matriz de riesgos, el informe aprobado y la presentación ejecutiva.

Entregables: flujo de recepción · carpeta documental · JSON · Excel de control · presupuesto · matriz de riesgos · informe Word · registro de aprobación · presentación PowerPoint · correo final de notificación.

Práctica propia

Adapta el flujo a un proyecto real anonimizado de tu trabajo.

Puedes utilizar una solicitud de proyecto, una orden de servicio, un plan de capacitación, una propuesta interna o una solicitud de cambio.

Antes de usar información real: elimina datos personales y credenciales; sustituye nombres por roles; elimina información contractual reservada; cambia identificadores internos; conserva únicamente los datos necesarios para practicar.

Outlook + Power Automate + SharePoint Paso a paso

  1. Descarga el correo de inicio y la ficha Word. Revisa la guía Power Automate.
  2. Construye un flujo que se active cuando el asunto contenga NUEVO PROYECTO · HORIZONTE.
  3. El flujo debe: detectar el correo; capturar remitente, asunto y fecha; verificar la ficha Word; crear carpeta MCP365_S2_F01_Recepcion_Proyecto_Horizonte; guardar el adjunto; registrar la recepción; enviar confirmación.
  4. No inventes endpoints, credenciales ni rutas reales de producción.

Copilot + Word + Power Automate Paso a paso

  1. Usa la ficha guardada en el Reto 1: MCP365_S2_Ficha_Proyecto_Horizonte.docx.
  2. Extrae código, nombre, objetivo, alcance, patrocinador, líder, fechas, presupuesto preliminar, entregables, dependencias, restricciones, riesgos y criterios de éxito.
  3. Copilot debe entregar un JSON estructurado. Si falta un dato: No especificado.
  4. No inventes fechas, cifras, responsables ni decisiones.
  5. Compara el JSON con el Word (validación humana) antes de continuar.
  6. Guarda: MCP365_S2_Datos_Proyecto_Horizonte.json.

Power Automate + Excel + Copilot Paso a paso

  1. Registra los datos del JSON en MCP365_S2_Control_Proyecto_Horizonte.xlsx.
  2. Completa la hoja Presupuesto con: código de partida, categoría, descripción, cantidad, costo unitario, costo total, responsable, fuente, tipo de cifra, estado de validación y observación.
  3. Diferencia valor confirmado, estimado y no especificado.
  4. Excel calcula subtotales, total, diferencia frente al preliminar y % de desviación.
  5. Power Automate agrega o actualiza filas. No modifiques una cifra confirmada sin aprobación humana.

Copilot + Excel + Power Automate Paso a paso

  1. Completa la hoja Riesgos del archivo de control (mismo Excel del Reto 3).
  2. Campos: identificador, riesgo, causa, consecuencia, probabilidad, impacto, nivel, control existente, tratamiento, responsable, fecha de revisión, estado, fuente.
  3. Distingue riesgo explícito, inferido, supuesto e información ausente.
  4. Todo riesgo inferido lleva la etiqueta Interpretación para validación.
  5. Ningún riesgo queda marcado automáticamente como validado.

Power Automate + Word + Approvals Paso a paso

  1. Usa la plantilla para crear MCP365_S2_Informe_Proyecto_Horizonte.docx con datos del JSON, presupuesto y riesgos.
  2. El informe incluye: identificación, resumen ejecutivo, objetivo, alcance, entregables, cronograma, presupuesto, desviaciones, riesgos prioritarios, dependencias, decisiones pendientes, recomendaciones, fuentes, validación humana y control de calidad.
  3. Power Automate: rellena plantilla → guarda → envía a aprobación → espera respuesta → registra decisión → notifica.
  4. Si es rechazado: registra observaciones, notifica y detén la presentación final.
  5. La aprobación nunca la completa Copilot. Validación humana y CQ quedan vacíos para la persona.
Precondición: el informe Word debe estar aprobado. Si fue rechazado, no generes la presentación.

Word + PowerPoint + Copilot Paso a paso

  1. Crea la presentación solo a partir de MCP365_S2_Informe_Proyecto_Horizonte.docx aprobado.
  2. Entre 8 y 10 diapositivas: portada, necesidad/oportunidad, objetivo y alcance, entregables, cronograma, presupuesto, riesgos prioritarios, decisiones pendientes, próximos pasos, cierre.
  3. Guarda como MCP365_S2_Presentacion_Proyecto_Horizonte.pptx.
  4. Copilot no agrega beneficios, cifras, fechas ni responsables que no aparezcan en el informe aprobado.
