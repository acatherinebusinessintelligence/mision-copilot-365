Sesión 2

Del documento disperso al comité directivo

Analiza, integra y transforma archivos empresariales mediante Microsoft 365 Copilot.

Principio pedagógico. “Copilot organiza, relaciona y propone. La persona verifica las fuentes, corrige el resultado y toma las decisiones.”

Herramientas disponibles

Los participantes cuentan con:

  • Microsoft 365 Copilot Chat.
  • Copilot en Outlook.
  • Word para consultar documentos.
  • Excel para consultar y validar datos.
  • PowerPoint para editar la presentación final.
  • OneDrive cuando esté disponible.
  • Carga directa de archivos en Copilot cuando esté habilitada.

No cuentan necesariamente con:

  • Copilot integrado dentro de Word.
  • Copilot integrado dentro de Excel.
  • Copilot integrado dentro de PowerPoint.
  • Automatizaciones empresariales fuera del alcance de esta sesión.

Trabaja siempre desde Microsoft 365 Copilot Chat (y Copilot en Outlook para el correo). No uses instrucciones del tipo “selecciona Copilot dentro de Word/Excel/PowerPoint”.

Ruta de trabajo

  1. Recibir o consultar el correo ficticio.
  2. Descargar los archivos adjuntos cuando sea necesario.
  3. Abrir Microsoft 365 Copilot Chat.
  4. Cargar o seleccionar los archivos.
  5. Referenciar claramente los archivos en el prompt.
  6. Ejecutar prompts progresivos.
  7. Verificar cada resultado contra los documentos originales.
  8. Construir los entregables.
  9. Llevar el contenido final a Word, Excel o PowerPoint.
  10. Preparar la comunicación ejecutiva final.

Caso · Proyecto Horizonte

Proyecto Horizonte · Modernización de infraestructura energética urbana

Una organización ficticia del sector energético estudia la modernización de una instalación para mejorar la confiabilidad del servicio en una zona urbana en crecimiento.

El equipo recibe información dispersa en diferentes archivos. Debe consolidarla para preparar una revisión ejecutiva del proyecto.

Aviso: todos los datos, nombres, cifras, instituciones y situaciones son ficticios y se utilizan exclusivamente con fines académicos.

Archivos del caso

Fuentes académicas ficticias. Trabaja con ellas desde Microsoft 365 Copilot Chat. El PDF del correo es referencia opcional; el instructor puede enviar el mensaje a tu bandeja.

Resultados de aprendizaje

Al finalizar, el participante debe poder:

  • Referenciar archivos correctamente.
  • Diseñar prompts fundamentados en fuentes.
  • Analizar un documento.
  • Analizar una hoja de cálculo.
  • Extraer compromisos de una transcripción.
  • Comparar varias fuentes.
  • Detectar contradicciones.
  • Construir una matriz de riesgos.
  • Preparar una presentación ejecutiva.
  • Redactar una comunicación para comité.
  • Diferenciar hechos, cálculos, inferencias y recomendaciones.
  • Verificar resultados producidos por Copilot.

  1. Descarga los archivos del caso.

Estructura del prompt profesional
  • Rol: define quién es Copilot (analista senior).
  • Contexto / fuente: limita el análisis al correo seleccionado.
  • Objetivo y tarea: lista explícita de elementos a identificar.
  • Criterios: diferenciar explícito, inferencia y no especificado.
  • Restricciones: no inventar ni usar información externa.
  • Formato: tabla, lista de tareas, preguntas y resumen acotado.
  • Verificación humana: contrastar cada hallazgo con el correo original.
